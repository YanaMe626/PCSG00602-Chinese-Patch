# PCSG00602 汉化资源结构

分析样本的 Title ID 为 `PCSG00602`，`APP_VER` 为 `01.00`，`VERSION` 为 `01.01`。ELF 以 `ARM:LE:32:v7` 加载，基址为 `0x81000000`。

## 剧情与系统文本

- `STORY.cpk` 含 281 个 STCM2L 脚本。`CODE_START_` 后是指令及内联数据，`EXPORT_DATA` 后是固定 40 字节的导出记录。导入器在扩充内联字符串后更新指令长度、偏移、调用地址、跳转地址及导出入口。
- `0x226` 的子类型 `0x65` 和 `0xC9` 分别显示对白及说话人，`0x213` 的已识别文本参数用于选项。
- 有些对白根据女主姓名走不同分支。调用的参数 1–3 和 5–7 分别保存默认姓名和自定义姓名的台词，参数 0 和 4 保存音频引用。
- `SYSTEM.cpk` 的 GSTR 表使用 `GSTL` 签名。每条记录含符号名偏移、ID 和文本偏移。

## 字库

系统和剧情各加载一份 FFU。字形由思源黑体简体中文 Regular 同步重绘，生成的两份 FFU 字节一致。原有字符保留 CP932 码位，新增汉字使用未占用的用户定义码位。

| ELF 地址 | 函数用途 |
| --- | --- |
| `0x8105B650` | 挂载 CPK 并注册两份 FFU |
| `0x810C585A`、`0x810C2AFE` | 安装字体并读取编码模式 |
| `0x810C33CC` | 解码一个字符 |
| `0x810C25A4`、`0x810C3A08` | 按编码查找字形记录 |
| `0x810C3026` | 解包 4bpp 字形像素 |
| `0x8109A430` | 查找 STCM2L 脚本导出 |
| `0x810367E0` | 注册系统字符串 |

FFU 使用 `UF` 魔数。`0x10` 起记录文件大小、区间表、字形记录和像素区偏移。区间记录是 `start`、`end_exclusive`、`base` 三个 32 位小端整数。字形记录保存宽度、高度、位图大小和相对像素偏移。`verify_eboot_font.py` 以本地 ELF 验证字符解码和字形查表。
